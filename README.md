Site da **Ventura Analytics**, construído 100% à mão — **HTML, CSS e JavaScript vanilla**. Zero frameworks, zero dependências, zero build. Abre o `index.html` e roda.

## ✨ Destaques

| Feature | Descrição |
|---|---|
| 🕸️ **Rede de partículas** | Canvas com nós conectados (estilo grafo de dados) que reagem ao mouse no hero |
| 💻 **Terminal interativo** | Digite `help`, `whoami`, `stack`, `cases` ou `contact` no terminal do hero |
| ⌨️ **Command palette** | `Ctrl+K` abre navegação rápida com busca, estilo Linear/Vercel |
| 🔀 **Pipeline animado** | Diagrama SVG com pacotes de dados viajando: fontes → ETL → warehouse → ML/BI |
| ✨ **Spotlight cards** | Brilho radial que segue o cursor em todos os cards |
| 🟢 **Status real** | Badge no footer pinga os sistemas em produção e mostra a latência |
| 🧮 **Orçador interativo** | Calculadora de orçamento por tipo de projeto, extras e prazo |
| 🎓 **Galeria de certificações** | 53 certificados com busca, filtro por categoria e visualizador de PDF |
| 🥚 **Easter eggs** | Abre o DevTools e vê o que acontece 👀 |

## 📁 Estrutura

```
├── index.html        # página principal (hero, serviços, pipeline, cases, orçador)
├── cursos.html       # galeria de certificações com busca e filtros
├── style.css         # estilos globais + features tech
├── cursos.css        # estilos da página de certificações
├── cursos.js         # busca, filtros e modal de certificados
├── tech.js           # command palette, easter eggs, micro-interações
├── certificados_img/ # thumbnails dos certificados
├── certificados_pdf/ # PDFs dos certificados
└── pictures/         # imagens do site
```

## 🛠️ Stack do site

`HTML5` · `CSS3` (grid, custom properties, backdrop-filter) · `JavaScript` (Canvas API, IntersectionObserver, SVG SMIL) · `JetBrains Mono` + `Inter`

## 🚀 Rodando local

```bash
python -m http.server 8000
# abre http://localhost:8000
```
